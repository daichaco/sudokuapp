# 既知の課題(次回改善時に対応)

2026-09-28 の提出後コードレビューで見つかった、コードは変更していない未対応の課題。

## 1. 曖昧な問題(解が複数ある盤面)で、正しい入力が「間違い」表示される

- **該当コード**:
  - `SudokuCore/Sources/SudokuCore/Hint.swift` の `HintEngine.mistakes(in:given:)`(74〜90行目)
  - `App/GameViewModel.swift` の `startGame()`(102〜114行目)と `hintTapped()`(176〜180行目)
- **原因**: `startGame()` は `Solver.countSolutions(board) > 0`(解が1つ以上あるか)しか確認しておらず、一意解であることを確認していない。`mistakes()` は `Solver.solve()` がたまたま見つけた1つの解とユーザー入力を比較しているため、解が複数ある問題では、ユーザーが別の正しい解を入力しても赤く表示され、ヒントも使えなくなる。
- **再現条件**: 「手で入力する」で、解が一意に決まらない(ヒントの数字が少なすぎるなど)問題を作って最後まで解く。写真から読み取った問題は `BoardCorrector` が一意解になるよう補正するため、起きにくい。
- **深刻度**: 中(クラッシュはしないが、ユーザーが混乱する)。
- **改善案**: `startGame()` で一意解チェックを追加して非一意な問題は開始させない、または `mistakes()` 側で「Solverの解と違う」だけでは赤くせず、実際の重複だけ赤くするよう変更する。

## 2. 入力のたびに全盤面データを書き出している

- **該当コード**: `App/GameStore.swift` の `save()`(98〜101行目)
- **内容**: 1文字入力するたびに、保存済みの全盤面(`records`配列全体、履歴は各盤面最大200件)をJSONにエンコードしてファイルへ書き出している。盤面数や履歴が増えると、入力のたびに少し重くなる可能性がある。
- **深刻度**: 低(現状の使用規模では問題になりにくい)。
- **改善案**: 保存を間引く(デバウンス)、または変更のあった盤面だけを差分保存する。

## 補足: テストについて(1. の修正時)

既存のテストは手入力の非一意な問題を扱っていないため、1. は検出されない(`swift test` は22件すべて成功)。修正するときは、次のテストを `SudokuCoreTests.swift` に追加する。

- 解が複数ある問題で、別の正しい解を埋めても `mistakes()` が空になること。
- 実際に重複がある入力は、引き続き `mistakes()` に含まれること。
