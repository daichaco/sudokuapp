# 既知の課題

2026-09-28 の提出後コードレビューで見つかった課題。2026-10-02 に、どちらも対応した。

## 1. 曖昧な問題(解が複数ある盤面)で、正しい入力が「間違い」表示される(対応済み)

- **原因**: `HintEngine.mistakes(in:given:)` が、`Solver.solve()` がたまたま見つけた1つの解とだけユーザー入力を比較していたため、解が複数ある問題で別の正しい解を入力すると赤く表示され、ヒントも使えなくなっていた。
- **対応**: `Hint.swift` の `mistakes()` で、見つけた解と違う入力は、そのマスに置いても問題が解けるかを確かめる。解けるなら(別の解に合うので)間違いにしない。どの解にも合わない入力と、行・列・ブロックの重複だけを赤くする。
- **テスト**: `SudokuCoreTests.swift` に次の3件を追加した。
  - `acceptsAlternativeSolutionOfAmbiguousPuzzle`: 別の正しい解を埋めても `mistakes()` が空になる。
  - `stillFlagsImpossibleEntryOfAmbiguousPuzzle`: どの解にも合わない入力は、曖昧な問題でも間違いになる。
  - `stillFlagsDuplicates`: 重複は、引き続き間違いになる。
- **残っていること**: 1つずつは別の解に合っていても、全部を合わせると解がなくなる場合は、最初に見つけた解と違う入力をすべて赤くする(まれなので許容)。

## 2. 入力のたびに全盤面データを書き出している(対応済み)

- **原因**: `GameStore.update()` が、1文字入力するたびに全盤面(履歴つき)をJSONにして書き出していた。
- **対応**: `GameStore` の保存を、最後の操作から0.5秒後にまとめて書き出す形にした(`scheduleSave()`)。アプリが裏に回るとき(`LibraryView` の `scenePhase`)は、`flush()` で待たずにすぐ書き出す。盤面の作成・削除・整理は、これまでどおり即時に保存する。
- **残っていること**: 操作から0.5秒以内にアプリが異常終了すると、最後の1操作が失われる。
