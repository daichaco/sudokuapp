# SudokuHelper

数独を解くのを手伝う iOS アプリ。紙の数独を撮影して盤面を読み取り、次の1手のヒントを理由つきで教えてくれます。

## 機能

- **盤面の読み取り** — カメラ（実機のみ・手動シャッター）または写真から数独を認識（Vision / Core Image）。読み取る前に、盤面の四隅を写真の上で合わせられます（自動検出した位置から微調整）
- **盤面一覧** — 「新しい盤面を始める」で、カメラ・写真・手入力から始められます。途中の盤面や完成した盤面が一覧に残り、続きから再開できます
- **戻す・自動保存** — 1手ずつ戻せます。操作のたびに保存されるので、アプリを閉じても続きから再開できます
- **自信のないマスの表示** — 読み取りで判定に自信がなかったマスをオレンジで示し、確認を促します（手書き・写りの悪い写真向け）
- **ヒント** — 「次の1手」を、ネイキッドシングル → ヒドゥンシングルの順に易しい手から提示し、理由を日本語で説明。論理で決まらない場合は解から1マスを示します
- **開発を応援する** — 盤面一覧の右上のハートから、任意の投げ銭(アプリ内課金の消耗型。¥160 / ¥480 / ¥1,000)ができます。支払っても機能は変わりません。商品IDは `App/TipStore.swift`、動作確認用の設定は `Config/Tips.storekit`
- **ソルバー** — 盤面の整合性チェックと解の探索

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `App/` | SwiftUI アプリ本体（`SudokuHelper.xcodeproj` から利用） |
| `SudokuCore/` | ロジックを集めた Swift Package（`Board` / `Solver` / `HintEngine` / `BoardRecognizer`）とテスト |
| `index.html` | ブラウザで遊べる単体の数独（依存なし） |

## 動作環境

- iOS 17 以降 / macOS 14 以降（`SudokuCore`）
- Xcode（Swift 6 ツールチェーン）

## ビルドとテスト

アプリ: `SudokuHelper.xcodeproj` を Xcode で開いて実行します。カメラでのスキャンは実機が必要です。

コアのテスト:

```sh
cd SudokuCore
swift test
```

## Web 版

`index.html` をブラウザで開くだけで動きます。
