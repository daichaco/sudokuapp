## 説明文(4000文字まで)
```
数独ヘルパーは、数独を解くのを手伝うアプリです。

【写真で読み取り】
新聞やパズル本の数独、パソコンやスマホの画面に映した数独を撮影するだけで、盤面を読み取ります。
盤面の四隅は自動で見つけ、ずれているときは指でドラッグして合わせられます。
読み取りに自信がない数字はオレンジで示すので、確認して直すだけです。

【理由つきヒント】
行き詰まったときは「ヒント」を押してください。
まず注目する範囲だけを示し、もう一度押すと場所と理由を教えます。答えをすぐに見せない、段階的なヒントです。

【便利な機能】
・候補の数字(メモ)の表示
・間違いの数字を赤くお知らせ
・1手ずつ戻せる「戻す」
・解答の表示
・盤面の自動保存。アプリを閉じても続きから再開できます
・盤面一覧で、途中の盤面や完成した盤面を見返せます

【プライバシー】
撮影した写真は端末の中だけで処理し、外部には送信しません。アカウント登録も広告もありません。

こんな方におすすめ
・新聞やパズル本の数独を、アプリでも進めたい
・詰まったところだけ、ヒントをもらいたい
・自分の解き方を確認したい
```

## 審査メモ(App Review Information の「メモ」欄)
```
ログインは不要です。
数独の盤面を「写真から読み取る」機能でカメラと写真を使います。撮影した画像は端末内でのみ処理し、外部には送信しません。
動作確認の手順:
1. 「新しい盤面を始める」→「手で入力する」を選ぶと、空の盤面が開きます。
2. マスをタップして数字を入力し、「開始」を押すとプレイできます。
3. 「ヒント」を押すと、次の1手を理由つきで表示します。
写真の読み取りは、写真ライブラリの数独の画像でお試しください。
```
